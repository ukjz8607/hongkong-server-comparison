## 香港服务器到底“好”在哪，什么情况下不值得买

香港服务器对大陆用户的核心价值只有两条：物理距离近，所以延迟低；不需要备案，域名解析就能上线。其余所谓优势，基本都是这两条的衍生结果。

从实测口径看，香港到大陆的 RTT 通常能压在 50ms 以内，GoMami 官方文档给的数字是香港节点 <30ms、东京 <50ms、新加坡 <70ms，首页宣传则统一写“RTT <50ms across mainland China”。这两个数字不冲突，一个是节点标称值，一个是面向全大陆的宣传口径。官方文档同时说明，实际延迟受本地 ISP、时段和网络状况影响。

不值得买的情况也很具体：

- 访客主要在欧美。三网优化带来的溢价你完全用不上，同样的钱在美西能买到更高配置。
- 预算只有几美元一个月。香港的带宽成本摆在那，这个价位能买到的“香港服务器”通常是共享国际带宽，晚高峰表现随缘——这一点后面单独展开。
- 你需要的是对象存储、CDN 或托管数据库这类托管服务，而不是一台可以自己折腾的机器。

## 判断一台香港服务器好不好，看这四个指标

真正决定体验的，是回程线路、晚高峰表现、单核性能和合同条款这四项，配置表上的核数和内存排在后面。

**回程线路**是最容易做文章的地方。CN2 是中国电信的精品骨干，比普通 163 骨干拥塞少；AS9929 是联通精品国际线；CMIN2 是移动较新的国际网络。三家都接入，电信、联通、移动用户才不会被丢到拥堵的普通回程上。很多标着“中国优化”的机器只优化了其中一条，另外两家用户的体验全靠运气。

**晚高峰**是分水岭。晚上七到十点，电信 163 拥堵、联通 169 拥塞、移动国际出口受限，白天跑满 1Gbps 的机器这时候可能只剩几十 Mbps。第三方测评对 GoMami 香港 Pulse 的记录是：下午时段三网回程分别走 CN2 / 9929 / CMIN2，联通 9929 在部分省份晚高峰有速率下滑和重传，但多线程基本能跑满；另有一份第三方整理的晚高峰单线程数据是电信 995 Mbps、联通 975 Mbps、移动 788 Mbps。这类数字只能当参考，各省差异很大，但它至少说明线路不是纸面优化。

**单核性能**决定数据库和动态页面的响应速度。GoMami 香港 Pulse 用的 EPYC 7763 加速 3.5GHz，第三方记录 Geekbench 单核 1100 分上下；香港 Turin 用的 EPYC 9575F 能到 5.0GHz，差距主要体现在 MySQL 这类单线程瓶颈场景。

**条款**最容易被忽略，也最容易在出问题时带来麻烦——超流量怎么算、DDoS 打到黑洞怎么处理、退款窗口多长。这三件事后面单独说。

## 600 Gbps 防护的真实边界

官网首页把“最高 600 Gbps DDoS 防护”放在显眼位置，但官方文档写得很直白：默认提供的是 **best-effort 基础清洗**，免费、自动、无需配置，不承诺清洗容量。600 Gbps 的专业清洗是**付费加购项**，需要联系销售。

更需要注意的是黑洞机制。当实例遭受大规模攻击、影响到同网段其他客户时，系统会自动给这个 IP 上黑洞，持续 30 到 60 分钟，自动解除，**无法人工干预**。这期间所有进出流量全部丢弃，业务完全不可用。文档还特别注明，因 DDoS 攻击导致 IP 被牵引的情况**不支持退款**。

这不是 GoMami 特有的问题，多数中小机房都是这个处理逻辑。区别在于有些商家不会把它写在文档里。如果你做的是容易被攻击的业务（游戏服、代理、某些灰色地带的应用），下单前应该把 600 Gbps 加购的价格问清楚，而不是默认它包含在套餐里。

## 为什么几美元一个月的香港服务器通常不好用

因为在这个价位上，商家卖给你的不是“香港优化线路”，而是一段共享的国际带宽——这两者的成本结构差着一个量级。

香港本地的机柜、电力和跨境带宽都不便宜，国际带宽尤其如此。三家运营商各建一条精品回程（CN2、AS9929、CMIN2）的成本，最终一定会摊到售价里。所以几美元一个月的香港 VPS，通常是这样组成的：共享的国际 BGP 出口，晚高峰靠抢；回程走普通 163 或国际线路兜底，不做三网优化；流量给得不大，或者带宽峰值标得很高但实际跑不满。

它在白天的测速截图里看起来和贵几倍的机器差不多，因为白天的国际出口根本不拥堵。问题出现在晚上七点到十点，这时候普通 163 骨干开始排队，你的 30ms 可能变成 300ms，丢包跟着上来。如果你的业务只是放个静态页、跑个不面向大陆用户的接口，这没什么影响；如果访客是大陆的付费用户，那就是另一回事了。

GoMami 这类定价偏高的商家，本质上是在卖“晚高峰期间的确定性”。它的机器参数在同价位里不算特别夸张，真正值钱的是三网回程和 600GB 级别的默认清洗（虽然只是 best-effort，但比完全没有强）。这也是为什么它的入门档是 $49 而不是 $9——中间那 40 美元，买的是线路和运维，不是 CPU 核心数。
